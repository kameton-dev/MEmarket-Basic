Представляем обновленный Microsoft Authenticator. Одно приложение для быстрого и безопасного подтверждения личности в Интернете, которое можно использовать для всех учетных записей.

Это приложение обеспечивает дополнительный уровень защиты при входе, часто называемый двухшаговой проверкой или многофакторной проверкой подлинности. Если активировать это приложение для рабочей или учебной учетных записей Майкрософт, вы получите уведомление при входе. Коснитесь для подтверждения - и все готово. Для других учетных записей или при нахождении в автономном режиме можно использовать встроенный генератор кода безопасности.

Новые возможности и обновленный дизайн доступны, только если вы установили юбилейное обновление для Windows 10. Без обновления у вас будет более старая версия приложения, поддерживающая только двухфакторную проверку подлинности для рабочей и учебной учетной записи.
