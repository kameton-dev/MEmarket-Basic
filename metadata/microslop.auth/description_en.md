Introducing the updated Microsoft Authenticator. One app for quickly and securely verifying your identity online, which you can use for all your accounts.

This app provides an extra layer of security when signing in, often referred to as two-step verification or multi-factor authentication. When you activate this app for your Microsoft work or school account, you'll receive a notification when you sign in. Tap to confirm, and you're done. For other accounts or when you're offline, you can use the built-in security code generator.

The new features and updated design are only available if you've installed the Anniversary Update for Windows 10. Without the update, you'll have an older version of the app that only supports two-factor authentication for your work or school account.
