# CMD.Injector_WP8
Командная строка для Windows Phone 8.

### Отказ от ответственности
> Автор не несет ответственности за любой ущерб, причиненный телефону этим приложением. Вы используете это приложение исключительно на свой страх и риск.

### Требования
* Windows Phone 8.1
* Разблокировка загрузчика.

* Разблокировка совместимости.

### Дополнительно
Для W10M ознакомьтесь с UWP-версией [CMD Injector](https://github.com/fadilfadz01/CMD.Injector).
