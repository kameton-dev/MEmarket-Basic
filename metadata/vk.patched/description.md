# VKClient_OVK
Клиент OpenVK для Windows Phone 8.1 и выше основанный на декомпилированном VK 4.12.

## Установка
Устанавливается любыми удобными методами установки .xap

Для Windows Phone 8.1 потребудется Interop Unlock

## Аааа у меня чтото сломалось
Если вы нашли баг то просьба создать Issue с описанием воспроизведения бага и скриншотом. Также по возможности приложите лог файл. Чтобы создать лог файл перейтите в настройки приложения -> диагностика -> включите ползунок Logs и попробуйте воспроизвести проблему, после снова зайдите в меню диагностики, сохраните лог и отключите логирование. Сохранённый лог может сразу не появиться в памяти телефона на компьютере, если файл не появился то переподключите телефон к компьютеру.
