# Unigram Mobile Messenger

Клиент Telegram, оптимизированный для платформы Windows 10 Mobile.

**ВАЖНО:** клиент устарел и не поддерживает все новые функции позже 2021-2022 годов (но это больше, чем ничего)

* [Скачать из Microsoft Store](https://www.microsoft.com/store/apps/9NSD4T15QLFX)
* [Группа в Telegram](https://t.me/UnigramMobile)

Благодаря [Universal Windows Platform (UWP)](https://docs.microsoft.com/en-us/windows/uwp/get-started/whats-a-uwp) приложение Unigram может работать на любом устройстве с Windows 10 (ПК, смартфоне, Xbox One, HoloLens и Surface Hub); оно интегрировано практически со всеми новыми функциями Windows и обеспечивает удобный, единообразный пользовательский интерфейс.
По договоренности с автором Unigram, этот форк продолжает поддерживать смартфоны на базе Windows 10 Mobile, тогда как поддержка этой платформы в оригинальном Unigram была прекращена в конце 2019 года. Однако официальные выпуски Unigram Mobile в Microsoft Store предназначены исключительно для мобильной платформы. Для других платформ используйте [оригинальный Unigram](https://github.com/UnigramDev/Unigram).

## Возможности
- На базе [TDLib](https://github.com/tdlib/td)
- Секретные чаты
- Мгновенный просмотр (Instant View)
- Поддержка нескольких аккаунтов
- Папки (например, «Непрочитанные»), синхронизируемые с другими клиентами Telegram
- Звонки
- Редактор фото (удобная обрезка, поворот, отражение и рисование на изображениях перед отправкой)
- Замена отправленных медиафайлов
- Опросы 2.0 и викторины
- Фоны 2.0 (доступны эффекты размытия и движения)
- Встроенная блокировка приложения с поддержкой аутентификации Windows Hello (распознавание отпечатка пальца, лица и радужной оболочки глаза)
- Расширенный редактор разметки (Markdown) для сообщений
- Встроенный музыкальный плеер
- Анимированные стикеры и эмодзи
- Отложенные и беззвучные сообщения
- Статистика для крупных каналов
- Полная поддержка уведомлений Windows 10 и Центра уведомлений (ответ на сообщение или пометка его как прочитанного без открытия приложения)
- Поддержка Continuum

## Поддерживаемые языки
В Unigram Mobile встроено 18 языков. Вы также можете создать собственный перевод или воспользоваться переводом, созданным другими пользователями.

Unigram Mobile предоставляет доступ к неограниченному количеству языковых пакетов через платформу переводов Telegram. Если вы хотите перевести приложение на свой язык, это можно сделать [здесь](https://translations.telegram.org/en/android/), так как Unigram Mobile использует те же переводы, что и официальное приложение Telegram для Android.

Однако термины, специфичные для Unigram Mobile, не переводятся через платформу Telegram; их можно перевести на другой платформе — [здесь](https://poeditor.com/join/project/Mes6DA3bhK).
