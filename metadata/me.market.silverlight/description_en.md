MEmarket Silverlight is the new Millennium Market app store client for Windows Phone 8.1, powered by simple JSON repositories that can be created by anyone, thereby distributing more apps. Replacing the old MEmarket client with WinRT.

> **IMPORTANT**
> The app is currently under active development. Be prepared for frequent updates and possible bugs.

---

## About Millennium Market

Millennium Market (MEmarket) is the official repository of proven and essential apps (MEmarket-Basic), along with a set of tools for customizing and conveniently working with the store. The project was created and continues to be developed by one enthusiast, thanks to the support of our small but close-knit community. MEmarket's main goal is to prove that this approach doesn't have to be complicated and accessible only to geeks. We are creating a platform that is as user-friendly and accessible as possible for every ordinary user.

## Features:

- **Canonical design** — an interface more closely aligned with the Windows Phone Store.
- **Repositories** — support for multiple repositories simultaneously and manage them.
- **Cross-platform** — support for Windows Phone 8.1 and Windows 10 Mobile apps.
- **Simplicity** — repositories are stored in a simple JSON format and are easy to generate and update.
