**MEmarket UWP** is a Millennium Market app store client for Windows 10 Mobile, powered by simple JSON repositories that can be created by anyone, thereby distributing more apps.

> **IMPORTANT**
> The app is currently in **active development**. Be prepared for frequent updates and possible bugs.

---

## About Millennium Market

**Millennium Market (MEmarket)** is the official repository of proven and essential apps (MEmarket-Basic), along with a set of tools for customizing and conveniently working with the store. The project was created and continues to be developed by one enthusiast, thanks to the support of our small but close-knit community. MEmarket's main goal is to prove that this approach doesn't have to be complicated and accessible only to geeks. We are creating a platform that is as user-friendly and intuitive as possible for every average user.

## Features:

- **Minimal dependencies** – simple C# / UWP architecture.
- **Update Tracking** — Fully featured package update functionality, tracking, and management.
- **Repositories** — Support for multiple repositories simultaneously and manage them.
- **Cross-platform** — Support for Windows Phone 8.1 and Windows 10 Mobile apps.
- **Simplicity** — Repositories are stored in a simple JSON format and are easy to generate and update.
